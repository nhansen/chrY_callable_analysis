Accuracy of variant calls within various commonly used callable-region masks
============================================================================

To estimate the accuracy of variant calls within different annotation classes and different callability masks, we used the variant genotypes from the short read variant calls described above to infer a Y chromosome “pseudo reference” for each sample, and then we measured the agreement between this constructed pseudo reference and the sample’s Verkko2 long read assembly.

Briefly, for each sample, bcftools was first used to create a sample-specific VCF file of variant calls and a sample-specific BED file of high confidence regions (both against the T2T-CHM13v2 reference) from the cohort VCF file produced in the short read variant calling step. To limit an analysis to regions of T2T-CHM13v2 within one of the three callability masks, the sample-specific VCF and high confidence BED file were intersected with the mask’s BED file using bedtools. The resulting set of called Y chromosome variants was then applied to the reference using “bcftools consensus” to generate a sample-specific pseudo reference sequence in FASTA format, as well as a chain file for lifting reference coordinates from T2T-CHM13v2 to the new sample-specific pseudo reference. Finally, the high confidence regions within the callable mask were lifted to the new sample-specific Y coordinates and used to mask any regions of the pseudo reference FASTA that were outside the callability mask or were not deemed high confidence in the original variant calling  (see script “sh.make_sample_gvcf_genome”, https://github.com/nhansen/chrY_callable_analysis).

Then, using minimap244 (v2.28) and GQC’s “compare” command, each masked pseudo reference FASTA file was aligned to its corresponding Verkko Y assembly for the same individual. To assess base level accuracy, differences between the pseudo references and the assemblies were counted as errors within each sequence class as defined by annotation along the T2T-CHM13v2 reference (see script “sh.run_gqc_compare_norandoms_minalign1000”, https://github.com/nhansen/chrY_callable_analysis). Error rates were combined within these sequence classes across individuals. For each sample and sequence class, the error rate was calculated as the number of errors in class / length of class and then converted to phred quality values using QV (-10*log10(error rate)). QV values were visualized across all individuals (Suppl. Fig. 92; https://github.com/sifordrebecca/functional_chrY) to view sample specific variation by sequence class and QV values were also averaged across samples for each class by totaling errors and class lengths across samples, then converting the overall error rate to phred quality values as above. Similarly, we produced QV estimates within the intersection of each sequence class and each of the global masks to compare sequence accuracy within the callable regions of each mask to see which mask called the highest QV sequence (Fig. 5i). Regions with zero discrepancies were reported as 60+ to indicate no observed errors. QV was not calculated for categories with fewer than 1000 aligned bases and are represented as white boxes.
